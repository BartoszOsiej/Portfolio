## Tech

- [Docusaurus](https://docusaurus.dev/) — generator statycznych stron
- Ciemny motyw aurora z glassmorphism
- Deployment via GitHub Actions → GitHub Pages

<details>
<summary><b>⚙️ Lokalny development</b></summary>

```bash
npm install
npm run start           # dev server z hot reload
npm run build           # production build do build/
npm run serve           # podgląd production build
```

Push do `main` — GitHub Actions buduje i deployuje automatycznie.
